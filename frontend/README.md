# frontend

2차 웹 (Next.js). 챗봇 결과 말풍선의 [자세히 보기]로 넘어온 사용자에게 근거 상세와 관측 원자료를 보여주는 읽기 전용 화면입니다.
1차 산출물인 챗봇 말풍선은 이 폴더에 없습니다. `/kakao-templates`(FE 소유, 선언형)에 있고, 렌더링은 `backend/src/server/templates/`가 합니다.

## 이 폴더가 하지 않는 것

- **판단하지 않는다** — 판정, 해석, 근거 보강은 전부 AI 파트의 결과이고, 이 폴더는 받은 것을 배치할 뿐입니다. 관측이 비었을 때 화면이 해석을 지어내는 경로가 있으면 버그입니다.
- **분석을 시작하지 않는다** — 웹은 이미 만들어진 `job_id`를 조회하는 진입점입니다. 이 폴더에서 외부 전송이 일어나면 안 됩니다.
- **대상 페이지에 접근하지 않는다** — 의심 URL을 `<a>`로 만들거나, 미리보기·썸네일·og:image를 불러오지 않습니다. 사용자 브라우저가 그 페이지에 닿는 순간 제품 전제가 깨집니다.
- **고지 문구를 짓지 않는다** — 동의/고지 로직은 현재 어디에도 존재하지 않습니다 (PM 최종 결정). 관련 코드를 발견하면 삭제 대상입니다.

## 하위 구조

| 폴더 | 역할 |
| --- | --- |
| `src/app/` | 라우트. 토큰 진입, 결과 상세, 공식 확인 경로 |
| `src/components/` | 표시 컴포넌트. 근거 카드 4칸, 판단 보류, 관측 목록 |
| `src/lib/` | 어댑터(BE 응답 → 뷰모델), 출력 가드, 폴링 |
| `mocks/` | BE 없이 전 화면을 돌리는 목 핸들러와 픽스처 |
| `tests/` | 가드 유닛 테스트 + 테스트 10건 중 FE 검증분 |

## 시작하기 전에

- `/contracts/schemas`의 스키마를 먼저 확인하세요. `src/lib/`의 타입은 전부 거기서 파생됩니다. **판정 값에 `safe`는 없습니다** — 없어야 실수로도 안전 보증이 나가지 않습니다.
- 화면에 값을 넘기기 전에 `src/lib/`의 가드를 반드시 통과시킵니다. 컴포넌트가 직접 원본 응답을 받는 경로를 만들지 마세요.
- 실제 스미싱 문자·URL로 테스트하지 않습니다. `mocks/`의 합성 데이터와 팀 소유 모형 페이지만 사용합니다.
