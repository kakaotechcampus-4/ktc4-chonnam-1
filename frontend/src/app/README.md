# app

라우트. 챗봇에서 넘어온 토큰을 받아 결과를 보여주는 것까지가 전부입니다.

| 경로 | 역할 |
| --- | --- |
| `/e/[token]` | 진입 인수. 토큰을 검증하고 `job_id`로 교환 |
| `/a/[jobId]` | 근거 상세와 관측 원자료 |
| `/routes` | 검토 등록된 공식 확인 경로 |

## 규칙

- **토큰 검증은 서버에서 합니다.** 토큰을 클라이언트로 흘려 BE를 직접 부르게 하지 않습니다.
- 토큰이 만료·중복 사용·위조인 경우 **이전 결과를 보여주지 않습니다.** 전용 안내 화면으로 끝냅니다.
- **낙관적 업데이트를 하지 않습니다.** 서버가 `done`을 주기 전에 결과를 먼저 그리지 않습니다. 아직 없는 관측을 화면에 먼저 띄우는 실수가 여기서 나옵니다.
- 상태는 서버 응답만 신뢰합니다. 진행 중에는 진행 중 화면이 정답이고, 그것도 결과입니다.
