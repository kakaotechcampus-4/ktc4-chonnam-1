# ai

LLM 호출·프롬프트·평가.

## 규칙

- **`server` 를 import하지 않습니다.** 카카오 payload, 카드 형식을 몰라야 합니다.
- 필요한 데이터는 인자로 받습니다. 백엔드 모듈을 뒤지지 않습니다.
- 입력 타입은 `types.py` 가 소유합니다.
- **판정하지 않습니다.** URL 추출과 설명 생성만 합니다.

## 역할

| 하는 일 | 위치 |
|---|---|
| 난독화 문자에서 URL 추출 | `llm/extract.py` |
| 판정 결과 → 설명 문장 | `llm/explain.py` |
| 프롬프트 (버전별 .md) | `prompts/` |
| 임계값·모델 설정 | `config/` |
| 평가셋·정확도 측정 | `eval/` |
