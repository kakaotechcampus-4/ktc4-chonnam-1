# 보강 조사 — 향후 검토

이 파일은 향후 보강 조사 설계를 위한 기록이며 프로토타입의 실행 프롬프트가 아니다.

프로토타입은 LLM에게 다음 도구 선택이나 최종 판정을 맡기지 않는다. RAG 유사도를 추가 검사 임계값으로 사용하지 않는다. 필요한 근거가 부족하거나 분석이 실패하면 확보된 근거와 한계를 보존하고 결정적 규칙에 따라 판단 보류 또는 분석 불가로 구별한다.

향후 Docker 기반 sandbox 구축을 논의한다. 실행 조건·수집 항목·멀티모달 모델 역할·반환 구조·한도·담당 경계는 미확정이다. 기존 도구 이름과 상태 필드 초안을 현재 계약으로 사용하지 않는다.
