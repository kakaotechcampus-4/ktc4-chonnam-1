# 설정 관리

추출·설명 모델, 검색 모델·검색 개수·유사도 척도, 시간·재시도 예산을 관리한다. 각 값의 의미·단위·범위·책임자·실험 근거와 버전을 기록한다. 미검증 값은 실험용으로 표시한다.

RAG 유사도는 검색 참고 정보다. 최종 판정이나 추가 검사 여부를 결정하는 유사도 임계값 또는 urlscan 점수와의 결합 가중치를 두지 않는다. 추출의 확신도와 사례 유사도도 구별한다.

결정적 판정의 세부 조건·우선순위와 코드 배치는 후속 확정 사항이다. 스캐너가 지원하지 않은 검사를 정상값으로 채우는 기본값을 두지 않는다.

첫 응답의 시간 기준은 docs/latency-budget.md를 따른다. 새 분석 단계의 예산과 백그라운드 종료 한도는 별도 합의하며 설명 생성 예산을 임의 전용하지 않는다. 작업 실행 한도는 백엔드가 강제한다.

설정·모델·프롬프트·KB·규칙 버전을 함께 기록한다. 프로토타입에서 향후 sandbox·멀티모달 분석을 활성화하는 설정은 추가하지 않는다.
