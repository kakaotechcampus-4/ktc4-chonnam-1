**채택한 설정**
- 지인 사칭 어휘가 나오면 가족 사칭·납치 사례 점수에 +0.03 가점(`search_by_identity`, `VOICE_IDENTITY_BOOST`).
- 사례 첨부 관문: 문자 n-gram + 어절 TF-IDF + 수법 단계 신호(계수 비음수) 선형 로지스틱 회귀(C=10), 학습은 KB 보이스피싱 483건 + 합성 정상 131건(대화 105 + 독백 26). 관문 점수 `VOICE_GATE_MIN` = 0.89 미만이면 사례를 붙이지 않는다. 유사도 기준값 `VOICE_MIN_SIMILARITY` = 0.0807. 기본 검색은 `voice.search_gated`. 판정(`decide_call`)은 바꾸지 않았다.
- 기준값·관문 기준·C 는 모두 dev 로만 골랐다.

**채택하지 않은 것**
- 상대 발화만으로 검색(Task 4): 실제 정상 포함 줄에서 hit@3 39.9 → 36.4%, 유형 평균 27.0 → 25.0% 로 오히려 떨어졌다(질의만 줄이면 대본 전체로 색인된 KB 와 문체가 어긋난다).
- 지인 filter·boost(순서만 바꾸기): 이득 0. 기관 어휘까지 앞세우기: 이득 없음.
- 정상 사례를 따로 색인해 대조(top1·majority): 단독·관문과 함께 모두 이득 없음.
- 실제 정상으로 학습한 관문: 로컬 실험일 뿐 배포하지 않았다.
- KoBERT: torch 의존성·지연. 역번역·SMOTE: 한국어 사례만 쓰기로 해서. 초반 150음절 질의(KT): 앞서 쟀고 이득 없음.

**알려진 한계**
- account_recruitment(계좌 모집)는 test 0/17 이다. 어휘표가 회사(COMPANY) 신원을 내지 않고, 관문 학습 정상(공식 앱 안내)과 문체가 겹친다.

- monologue 정상 부착이 기준선 2.3% → 12.9% 로 올랐다(call 은 5.8% → 3.0%). 독백형 학습 정상 26건이 실제 독백(KorCCVi)과 문체가 다르다. 실제 독백형 통화가 많은 환경이면 오탐이 늘 수 있다.
- 가족 사칭·기타 사칭은 KB 와 평가 모두 합성뿐이다(실제 사례 없음). 기타 사칭은 test 에서 오히려 6 → 4/16 으로 줄었다.
- 표본이 작다: 소수 유형은 유형당 test 13~17건. 가족·납치의 상승은 지인 어휘 가점 때문이라 어휘에 의존한다.
- test 정상 부착률 5.7% 는 dev 4.9% 보다 높다(관문 기준·C 를 dev 로 골라 표본에 민감). 5% 상한을 test 에서 보장하지는 못한다.
- 합성 정상 부착 0.0% 는 학습 합성과 같은 문체라 낙관적이다. 정상 부착률은 실제 오탐률이 아니다.
- AI Hub 정상으로 학습한 관문은 로컬 실험(dev 정상 절반으로 학습, 나머지로 측정)에서 hit@3 94.2%, 실제 정상 부착 1~2% 였지만 합성 hard negative(가족 급전 부탁·진짜 경찰 연락)는 절반가량 붙었고 학습·평가가 같은 출처라 낙관적이다. AI Hub 파생 가중치의 배포 조건이 확인되지 않아 **저장소·배포에 넣지 않았고, 배포 여부는 사용자 결정**이다.
- 정상 부착률은 데이터 구성(AI Hub 상담 녹취 위주)에 의존한다. 실제 환경 정상 통화 분포가 다르면 달라진다.

## Task 5: 신원 주장으로 유형 우선

신원 어휘(`ai.case.lexicon.identity_kinds`, 결정적·LLM 없음)가 나오면 대응 유형 사례를 앞세운다. 평가 옵션 `--identity {acquaintance,all} --identity-mode {filter,boost,score} --identity-boost N`. 지인(ACQUAINTANCE)은 가족 사칭·납치, 기관(INSTITUTION)은 기관 사칭·대출 빙자에 대응시켰다. 어휘표는 회사(COMPANY)를 내지 않아 기타 사칭·계좌 모집은 앞세울 근거가 없다. 질의는 평가셋 `text` 전체, 어휘는 화자 구분 없이 전체 글에서 찾는다.

방식 세 가지:
- filter: 기준값 이상 후보 중 해당 유형만 남긴다(없으면 그대로).
- boost: 기준값 이상 후보 안에서만 순서를 바꾼다. 붙일지는 원점수 1위로 정해 판정에 영향이 없다.
- score: 해당 유형 점수에 가점을 더해 순위와 기준값 비교에 모두 반영한다. 기준값은 다시 고른다(부착 5% 상한).

| 설정 | 정상 구성 | 기준값 | hit@3 | 유형 평균 hit@3 | 정상 부착률 |
|---|---|---|---|---|---|
| 기준선 | 실제 정상 포함 | 0.1121 | 39.9% | 27.0% | 4.9% |
| 지인 boost(순서만) +0.03 | 실제 정상 포함 | 0.1121 | 39.9% | 27.0% | 4.9% |
| 지인 score +0.01 | 실제 정상 포함 | 0.1121 | 39.9% | 27.0% | 4.9% |
| **지인 score +0.03** | 실제 정상 포함 | 0.1122 | **44.5%** | **35.4%** | 5.0% |
| 지인 score +0.05 | 실제 정상 포함 | 0.1141 | 43.4% | 37.1% | 5.0% |
| 기준선 | 프로젝트 합성만 | 0.0724 | 74.6% | 61.6% | 4.8% |
| 지인 filter / boost(0.01~0.05) | 프로젝트 합성만 | 0.0724 | 74.6% | 61.6% | 4.8% |
| 지인 score +0.01 | 프로젝트 합성만 | 0.0724 | 77.5% | 66.8% | 4.8% |
| **지인 score +0.03** | 프로젝트 합성만 | 0.0730 | **77.5%** | **67.6%** | 4.8% |
| 지인+기관 score +0.01 | 프로젝트 합성만 | 0.0734 | 75.1% | 61.8% | 4.8% |
| 지인+기관 score +0.03 | 프로젝트 합성만 | 0.0792 | 73.4% | 58.6% | 4.8% |

- 순서만 바꾸는 방식(filter·boost)은 이득이 0이다. 놓친 질의 대부분은 정답 유형 사례가 순위가 아니라 기준값 밑이라서 못 맞힌다. 이득은 점수에 가점을 줄 때만 나온다.
- 실제 정상 포함 줄(+0.03): 유형별 가족 사칭 0/16 → 6/16, 납치 2/16 → 4/16, 나머지 유형 변화 없음. 프로젝트만(+0.03): 가족 6 → 8/16, 납치 6 → 11/16, 기관 사칭 74 → 73/82, 기타 사칭 13 → 12/15.
- 기관 어휘까지 앞세우면(`all`) 기관 사례가 이미 많아 이득이 없고 기준값만 올라 유형 평균이 떨어진다. 채택하지 않았다.
- 판정: **채택(지인 score +0.03).** 채택 기준(실제 정상 포함 줄에서 hit@3·유형 평균 하락 없음, 부착률 5% 이하)을 충족한다. +0.05 는 유형 평균이 더 높지만 hit@3 이 낮고 기관 사칭이 줄어(46 → 42/82) 고르지 않았다.
- 운영 반영: `ai.case.voice.search_by_identity` 가 대본의 지인 어휘를 보고 `search_voice_cases(preferred_types=...)` 에 가족 사칭·납치를 넘긴다. 어휘표만 쓰므로 읽기(LLM)와 나란히 돌리는 구조가 그대로다. 평가와 운영이 `search.boost_types` 를 함께 쓴다. `decide_call` 은 바꾸지 않았다.
- 한계: 점수에 가점을 주므로 붙일지의 결정도 바뀐다(정상 부착은 기준값을 다시 골라 5% 이내로 맞췄다). 지인 어휘는 정상 대화에도 흔해(`엄마`·`친구`) dev 의 family 정상(17건)이 이미 부착률이 높다. 실제 정상 test 는 보지 않았다. 코드의 `VOICE_MIN_SIMILARITY`(0.0588)는 이번 기준값 재선택에 맞춰 바꾸지 않았다. 가족 사칭은 KB 에 28건뿐이라 dev 표본(16건)이 작다.

## Task 6: 사례 첨부 관문 (보이스피싱 같음 점수)

검색에 정상 사례가 없어 유사도 기준값 하나로는 실제 정상 통화(은행·민원 상담)와 보이스피싱을 가르지 못했다. 대본이 보이스피싱 통화와 같은지 점수를 내는 선형 분류기(관문)를 두고, 점수가 기준 미만이면 사례를 붙이지 않는다. 판정(`decide_call`)·결론·근거는 바꾸지 않는다.

- 모델: 문자 n-gram(2~4) TF-IDF 2만 개 + 어절 TF-IDF 4천 개 + 수법 단계 신호 8개(기관·지인 신원 어휘, 요구 종류 셋[돈·비밀 정보·기기/메신저], 끊지 못하게 하는 말, 급박·비밀 유지, 구실) → 로지스틱 회귀(class_weight balanced). TF 1+ln(tf), 묶음마다 L2 정규화.
- 배포 가중치 학습 데이터(저장소에 둘 수 있는 것만): 양성 = voice KB 보이스피싱 483건, 음성 = 학습 전용 합성 정상 105건(`datasets/voice_gate_train.jsonl`, 정상 유형 6종 × 틀 12~13개, `split: train`, KB·dev·test 와 group 겹침 0). dev/test 질의는 학습에 쓰지 않았다.
- 학습은 sklearn(시스템 Python, `eval/voice_gate_train.py`), 운영 추론은 순수 Python(`ai.case.attach_gate`, 모델 `src/ai/kb/voice_gate.json` 1.26MB). 같은 입력에서 sklearn 점수와 소수 6자리까지 같다(테스트).
- 선택: dev(실제 정상 포함, qa_written 제외) 정상 부착률 ≤ 5% 에서 hit@3, 다음으로 유형 평균. 관문 기준 g 를 0.01 간격으로 훑고 g 마다 유사도 기준값을 다시 골랐다. 검색은 Task 5 운영 설정(지인 score +0.03) 그대로.
- 대조 방식(옛 Task 6): 같은 합성 정상 105건을 따로 색인해, 정상 사례가 top-1 이거나(top1) 상위 3개 중 2개 이상이면(majority) 붙이지 않는다.
