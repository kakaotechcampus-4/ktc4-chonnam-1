## 해석

### 이전 리포트와의 관계

KB 와 평가 행이 모두 바뀌었다. KB 는 296건에서 443건이 됐고(유형 라벨 428건), 평가 스미싱은 215건에서 62건(dev 31 / test 31)이 됐다. 그래서 `2026-10-03-rag-tfidf.md` 등 이전 리포트 수치와 직접 비교하지 않는다. 분할 방법은 `docs/superpowers/specs/2026-10-03-rag-kb-eval-split-design.md` 를 따른다.

### 이번 결과 (test)

| 지표 | 값 |
|---|---|
| 스미싱 hit@3 | 25.8% (8/31, 95% 구간 13.7%~43.2%) |
| 스미싱 MRR | 0.242 |
| AUC 스미싱 vs 정상 / vs hard negative | 0.631 / 0.643 |
| 정상 / hard negative 부착률 | 6.7% / 12.0% |
| 질의 p95 · 첫 호출 | 4.87ms · 384.9ms |

- KB 사례가 0건인 유형이 없어져 hit@3 의 구조적 상한이 사라졌다.
- AUC 는 이전 리포트들보다 높다(0.6 대). 다만 평가 행이 달라 직접 비교하지 않는다.
- hard negative 부착률이 dev 4.6% 에서 test 12.0% 로 벌어졌다. 기준값이 dev 템플릿 66개로 정해져 test 템플릿 88개로 그대로 옮겨지지 않는다. 기준선(`2026-10-03-rag-jaccard.md`)에서도 4.6% / 11.3% 로 같은 현상이 있었다.
