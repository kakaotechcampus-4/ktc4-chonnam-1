# 사례 검색 임베딩 혼합: 스미싱 · 링크 없는 사칭 · 보이스피싱

실행일: 2026-10-31 · 임베딩: `text-embedding-3-large`(엘리스 ML API, 3072차원) · 추출 캐시 모델: `LLM_MODEL`

> 정상·hard negative 문자와 정상 통화 일부는 합성이다. 부착률을 실제 오탐률로 인용하지 않는다.
> 설정은 dev 에서만 골랐고 test 는 설정을 고정한 뒤 한 번 봤다.

## 지표

사용자 결정(2026-10-31): 목표 60% 는 **순위 hit@3**(기준값 없이 상위 3개 안에 같은 유형 사례)로 재고,
정상 부착률(기준값 이상 사례가 붙는 비율, dev 5% 이하로 기준값을 고른다)은 따로 본다. 기존 리포트의
hit@3(기준값 포함)도 함께 적는다.

- 링크 없는 사칭: `eval/datasets/README.md` "링크 없는 사칭 문자 (2026-10-31)" 의 23행(dev 11 · test 12).
  `other` 3행은 KB 에 같은 유형이 없어 맞힐 수 없다(test 최대 11/12).
- 스미싱: 나머지 스미싱 행(dev 40 · test 40).
- 보이스피싱: `voice_rag.jsonl` + 로컬 licensed, 실제 정상 통화(`--extra-normals`) 포함. 운영 경로(신원 가점 →
  기준값 → 관문 `VOICE_GATE_MIN`) 그대로.

## 채택 설정

| | 점수 | 기준값(dev 정상 부착 5% 이하) |
|---|---|---|
| 문자 | 0.3 · TF-IDF + 0.7 · 임베딩 코사인(variant 최댓값) | 0.5463 |
| 통화 | 0.5 · (TF-IDF + 신원 가점) + 0.5 · 임베딩 코사인(1,500자 조각 평균 벡터) | 0.3042 |

임베딩이 설정되지 않았거나 KB·질의 임베딩이 실패하면 기존 TF-IDF 와 기존 기준값으로 돌아간다(`ai.kb.semantic`).

| 링크 없는 사칭 | **혼합** | **11/12 (91.7%)** | 6/12 (50.0%) | |
| 보이스피싱 | TF-IDF | 168/171 (98.2%) | 110/171 (64.3%) | 5.7% |

- 운영 함수(`search_cases`)로 다시 재면 질의 681건 중 6건(0.9%)이 임베딩 0.6초 한도를 넘겨 TF-IDF 로
  폴백했다. 순위 hit@3 는 같고, 기준값 포함 hit@3 는 1건씩 다르다(링크 없는 사칭 test 5/12).
- 화자 분리를 뺀 통화 코드(ADR 0007 작업)와 합쳐 다시 재도 통화 수치는 같았다.
- `--with-licensed`(실물 메신저 정상 포함)로 고른 기준값에서는 문자 test 기준값 포함 hit@3 가 스미싱 42.5%,
  링크 없는 사칭 66.7%, hard negative 부착 6.3% 였다.

## 한계

- **문자의 기준값 포함 hit@3 는 본문만으로는 오르기 어렵다.** 순위는 dev 48/51 이 맞지만, 상위 hard negative
  가 짝지은 KB 사례가 본문이 정상 알림과 같고 위험이 링크에만 있던 스미싱이다(예: CE-0221 "한진택배 내일오후
  1시~4시경에 고객님 상품이 배송 예정입니다"). 지인 사칭도 정상 "엄마 나 휴대폰 고장나서 서비스센터 왔어"와
  사기 "엄마 친구가 휴대폰 가져가서 번호가 바뀌었어"가 거의 같다.
- 평가셋 정상 문자로 관문을 학습하면 test AUC 0.93 이 나오지만 평가셋을 외우는 것이라 쓰지 않았다.
  실제 정상 알림 문자(팀원 수신 등)를 모으면 관문 학습을 다시 볼 수 있다.
- test hard negative 부착이 dev(4.6%)보다 높다(10.8%). TF-IDF 도 test 8.1% 였다. 표본이 작다(test 148행).
- 질의 임베딩은 연결 재사용 시 p50 0.32초 · p95 0.44초 · 최대 0.58초(120건). 문자 검색 예산 1초 안에서
  0.6초 한도 후 TF-IDF 로 폴백한다.

## 재현

`ai/` 에서 시스템 Python(numpy·sklearn). 임베딩·추출 캐시는 저장소 밖 `~/.cache/ktc4-rag`(`RAG_EMBED_CACHE`).
`eval/embed_cache.py` 는 평가 실행 때만 저장소 최상위 env 파일의 값을 환경변수로 올린다(값은 출력하지 않는다).

```bash
PYTHONUTF8=1 PYTHONPATH="src;eval;.venv/Lib/site-packages" python eval/embed_rag_experiment.py --mode mix --alpha 0.3 [--test]
PYTHONUTF8=1 PYTHONPATH="src;eval;.venv/Lib/site-packages" python eval/embed_voice_experiment.py --alpha 0.5 --pool mean --extra-normals <로컬 normal_real.jsonl> [--test]
```

실험 스크립트의 hit@3 출력은 기준값 포함 값이다. 순위 hit@3 는 기준값 0 으로 같은 함수를 부른 값이다.
