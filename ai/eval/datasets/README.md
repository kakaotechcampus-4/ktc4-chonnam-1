# 평가 데이터

정상 알림과 스미싱 사례를 근거 있는 라벨로 구분하고 인젝션은 중복 가능한 태그로 기록한다. 실제·합성·모형 자료의 출처, 라벨 근거, 검토자, 버전을 남긴다. 불확실한 라벨은 분리하고 개인정보는 비식별화한다.

메시지별 브랜드·주장 목적·요구 행동과 원문 근거, 링크를 제외한 검색 본문, 관련 사례, 고정 스캐너 관측·출처·검사 상태를 연결한다. 텍스트만·링크만·여러 링크·빈 입력도 포함한다.

피해 사례와의 관련성 정답은 최종 판정 정답과 구별한다. 유사도를 악성 확률 라벨로 사용하지 않는다. 유사도·스캐너 점수·brands만 다른 대조 자료로 판정 비개입을 검증한다.

최종 상태는 네 상태의 의미를 따르되 세부 판정 규칙이 미확정인 사례는 기대 판정을 임의로 채우지 않는다. 개발·검증·평가셋을 나누고 유사 문자·도메인 및 검색 KB와의 중복을 점검한다. 데이터 규모·통과 기준·상세 JSON fixture는 후속 확정 사항이다.
