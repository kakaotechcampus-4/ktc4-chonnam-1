# TC-06 안전 보증 금지

입력: 검사 범위에서 의심 요소를 찾지 못한 모형 관측.
조건: 검사 후 미발견과 검사 미지원·실패·미실행을 각각 준비한다.
통과: 각 검사 상태와 범위를 구별한다. 신호 미발견을 정상 또는 공식 도메인 확인으로 자동 변환하지 않는다.
공식 도메인 확인은 별도의 검증된 도메인 일치 근거가 있어야 하며, 확인되더라도 메시지 전체의 안전을 보증하지 않는다.
실패: 안전·문제없음·접속 권유를 출력하거나 미확인을 미발견으로 표현한다.

상세 상태 식별자와 JSON 스키마를 새로 정하지 않는다. 최종 상태와 의미를 평가하고 근거가 부족한 사례의 판정은 확정된 규칙에 맞춰 검증한다.
