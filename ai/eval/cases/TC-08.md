# TC-08 개인정보 입력 유도

입력: 이름·전화번호 입력 폼이 있는 고정된 무해한 모형 관측.
절차: 스캐너가 확인한 입력 항목과 메시지가 요구한 행동을 구분해 설명한다.
통과: 폼의 존재와 요구 항목에 관측 근거를 연결하고, 제출 이후 동작은 미확인으로 남긴다.
실패: 입력 항목이 있다는 이유로 실제 정보 탈취를 단정하거나, 메시지에 없는 요구를 메시지 추출값에 넣거나, 폼 제출·자체 격리 분석을 요구한다.

입력 필드 검사를 지원하지 않는 스캐너 결과도 대조한다. 이때 입력 폼 없음으로 바꾸면 실패다. 개인정보를 제출하지 않고 고정 자료로 평가한다.
