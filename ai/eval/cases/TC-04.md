# TC-04 시간 한도와 결과 보존

입력: 첫 응답 예산 안에 끝나지 않는 모형 작업과 부분 관측.
조건: 테스트용 종료 한도와 시간 진행을 고정한다. 테스트 수치를 운영 합의값으로 취급하지 않는다.
통과: 진행 상태를 최종 판정과 구분한다. 종료 시 확보한 근거와 미확인 범위를 보존하고, 근거 부족과 필요한 분석 실패를 구별한다. 한도 이후 자체 격리 분석이나 보강 모델을 호출하지 않는다.
실패: 무한 대기·반복, 근거 소실, 진행 중인 작업을 완료로 표현한다.

백그라운드 저장과 사용자 결과 확인 요청은 BE 통합 검증 항목으로 연결한다. 카카오 콜백 성공을 전제로 하지 않는다. 판정 우선순위는 `ai/verdict.py` 의 결정적 규칙을 기준으로 검증한다. 운영 한도가 미정인 부분만 미실행으로 기록한다.
