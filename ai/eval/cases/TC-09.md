# TC-09 입력 유형

| 입력 | 기대 결과 |
|---|---|
| 텍스트와 링크 1개 | 추출·검색과 링크 분석 결과 사용 |
| 링크만 1개 | 추출·검색 생략, 링크 분석 결과만 사용 |
| 텍스트만 | 추출·검색 참고 정보와 링크 입력 요청. 링크 기반 최종 판정 없음 |
| 링크 N개, 전부 공식 | 공식 도메인 확인 |
| 링크 N개, 비공식 1개 | 그 1개를 분석 |
| 링크 N개, 비공식 2개 이상 | 하나를 선택하도록 요청 |
| 둘 다 없음 | 문자 입력 요청 |

백엔드에서 분리된 입력과 고정 링크 관측으로 AI 흐름을 검증한다. 링크만 있다는 이유로 격리 분석을 필수 호출하지 않는다.
실패: 없는 URL 생성, 링크 임의 선택, 텍스트 없음에 유사도 0 부여, 입력 보완 요청에 최종 판정 강제, 링크 없음으로 정상 판정.
URL 추출의 전각·제로폭·문장부호 경계와 중복 계산은 백엔드 계약 확정 후 통합 검증하며 여기서 새 규칙을 정하지 않는다.
