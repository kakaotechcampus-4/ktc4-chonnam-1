# 필수 회귀 케이스

TC-01~13은 주장·관측 구분, 접근 실패, 인젝션, 시간 한도, 근거 충실성, 안전 보증 금지, 설치·입력 요구, 입력 유형, 공식 도메인 확인을 검증한다. 기준은 AI 설계 문서다.

각 파일에 입력·조건·기대 결과·실패 기준을 둔다. 판정 규칙과 스키마는 `ai/verdict.py`, `ai/types.py`로 확정됐으므로 그 기준으로 검증한다. 13건은 전체 평가셋을 대체하지 않는다.

추가 평가에는 세 추출 항목의 정확성, RAG 검색 품질·실패 처리, 유사도·스캐너 점수·brands의 판정 비개입, 스캐너 교체와 미지원 항목, 설명 폴백을 포함한다. 상세 JSON fixture는 계약 확정 후 작성한다.

결과는 reports에 새 기록으로 남기며 과거 보고서는 보존한다. AI 검증은 고정 관측과 가짜 응답을 사용하고 저장·조회·화면 검증은 담당 파트의 통합 검사와 연결한다.
