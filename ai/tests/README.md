# 코드 검증

아래 체크리스트는 전체 프로토타입 검증 기준이며 향후 연동 작업을 포함한다. 구조화 분석 계약 테스트와 실행 명령은 아래와 같이 구현되어 있다.

- 브랜드·주장 목적·요구 행동을 원문 근거와 함께 추출하고 누락·모호한 항목은 미확인으로 남긴다.
- 텍스트만·링크만·둘 다 있음·여러 링크·빈 입력 분기를 AI 설계와 맞춘다.
- RAG는 링크를 제외한 마스킹 본문을 사용하며 검색 실패를 유사도 0으로 바꾸지 않는다.
- 관측이 고정된 상태에서 RAG 유사도·스캐너 점수·brands만 바꿔도 최종 판정은 유지한다.
- 발견·검사 후 미발견·미확인과 관측·모델 해석·사례를 구별한다.
- 모델·검색 실패 시 확인된 근거를 보존하고 설명 실패 시 템플릿을 사용한다.
- 미검토 KB와 근거 없는 인용·설명을 제외한다.
- `ai/`가 격리 서버를 직접 호출하지 않는지 확인한다.
- 네 가지 최종 상태, 일부 관측 실패와 근거 충돌을 검증한다.

고정 fixture와 가짜 모델·스캐너 응답을 사용한다. 구조화 분석 계약 테스트는 아래에 구현되어 있다. 장시간 작업 저장·조회는 BE 통합 검증과 연결하되 이 문서가 구현 계약을 새로 정하지 않는다. 검증된 실행 명령은 아래에 있으며 품질 평가는 eval에 둔다.

## 실행

저장소 루트에서 다음 명령으로 의존성을 설치하고 AI 테스트를 실행한다.

```powershell
python -m pip install -e "./ai[test]"
python -m pytest ai/tests -q
```

구조화 분석 테스트는 고정 JSON 계약, 전체 분류 코드, `other/custom_label`,
근거 검증에 따른 선택적 필드 제거, API 실패·거부·타임아웃 폴백, 프롬프트
인젝션 경계를 검증한다. 기본 테스트는 실제 LLM API를 호출하지 않으며 가짜
클라이언트를 사용해 네트워크 없이 실행된다.
