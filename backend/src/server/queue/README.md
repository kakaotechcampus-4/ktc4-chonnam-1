# backend/src/server/queue

5초 응답 제한을 넘기는 작업을 처리하는 비동기 작업 큐. 카카오 콜백(최대 1분)에 맞춰 동작합니다.

## 역할

- `api/`가 `useCallback: true`로 즉시 응답한 뒤, 실제 파이프라인(③~⑥)은 이 큐의 워커가 백그라운드에서 처리합니다.
- 1분 내에 끝나면 콜백 URL로 결과를 전송합니다.
- 1분을 넘기면 **콜백을 보내지 않고** `chatbot_sessions`/`jobs` 상태만 갱신해둡니다. 사용자가 `check_result` 재요청을 보내야 결과를 받습니다.

## 지켜야 할 규칙

- 상태는 한 방향으로만 진행시킵니다 (`running` → `observed` → `done`/`held`). 이미 지나간 상태로 되돌리지 않습니다.
- 재시도 시 멱등성을 보장합니다 — 같은 작업이 중복 실행돼도 결과가 두 번 쌓이지 않습니다 (N07).
- 콜백 전송 성공 여부와 무관하게, 이 큐가 만든 최종 상태는 `GET /api/analyses/{job_id}`로 항상 조회 가능해야 합니다.
