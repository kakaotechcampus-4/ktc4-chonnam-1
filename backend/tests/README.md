# backend/tests

기획안 테스트 케이스 10건과 BE 고유 회귀 테스트.

## 우선 작성할 것

- **프롬프트/템플릿 인젝션 픽스처** — 관측 대상 페이지 본문에 지시문을 삽입한 샘플로, `clients/`·`templates/`가 이를 데이터로만 처리하는지 검증 (`/ai/eval/datasets`의 `injection` 세트와 공유 가능한지 AI팀과 확인)
- **조회 한도 테스트** — 한도 도달 시 AI 재호출 없이 `held`로 종료되는지
- **근거 없는 해석 방지 테스트** — `observations`가 비었을 때 `interpretation`이 생성되지 않는지
- **안전 보증 금지 테스트** — 응답 어디에도 보증 표현이 없는지 (CI 상시 포함)
- **세션 중복 전송 방지 테스트** — `analyzing` 상태에서 재요청이 새 작업을 만들지 않는지, 동시 요청 레이스 컨디션 테스트 포함
- **콜백 타임아웃 테스트** — 1분 초과 시 콜백을 보내지 않고 상태만 갱신하는지

## 지켜야 할 규칙

- 실제 외부 API·AI 서비스를 호출하지 않고 목업으로 테스트합니다.
- 9~10주차부터 이 폴더의 테스트가 CI 필수 통과 조건이 되고, 신규 기능 머지가 금지됩니다.
