# 쓰레기 과태료 문자: 주의 기준과 반례

- 작성일: 2026-10-07
- 상태: **검토용 초안. 운영 판정 규칙·응답 계약에 반영하지 않음.**
- 확정한 방향 (2026-10-07, 사용자 선택): 기관·지역을 특정하지 못하는 알려진 수법은 **주의 필요로 안내하고 추가 분석**한다. 별도의 검증된 위험 행동이 있으면 그 근거로 경고한다.
- 목적: 검증된 사칭 수법에는 일관되게 경고하고, 새 문자에서는 구체적인 근거를 분석한다.
- 관련: [결과 의미 사례표](result-meaning-cases.md), [현재 응답 계약](../scheme.md),
  [참고 자료 양식](../../ai/src/ai/kb/norm_rules/template.md).

## 1. 위험도 대신 우선 정할 것

이 문서의 등급은 사용자에게 권하는 **주의 수준**이다. 악성 확률이나 실제 과태료 부과 여부가 아니다.
등급과 별도로 확인한 사실, 확인하지 못한 범위, 사용자의 다음 행동을 설명한다.

| 제안 등급 | 의미 |
| --- | --- |
| 높은 주의 | 적용 가능한 공식 절차와의 명확한 충돌 또는 별도로 검증한 위험 행동이 있음 |
| 주의 필요 | 알려진 사칭 수법과 요구 행동이 닮았지만 기관·지역·현재 절차 등을 확인하지 못함 |
| 확인 필요 | 위 근거를 확보하지 못함. 정상·안전 판정으로 해석하지 않음 |

예방 공지나 인용문은 공격자가 사용자에게 하는 요구와 구별한다. 해당 구절 때문에 경고하지 않는다는
뜻이며, 문자에 포함된 다른 링크·요구까지 안전하다고 인정하는 것은 아니다.

## 2. 공식 자료가 확인해 주는 범위

| 자료 | 확인된 내용 | 그대로 확장하면 안 되는 내용 |
| --- | --- | --- |
| 전주시, 2024-01-16 | 관공서 사칭, 쓰레기 투기 신고 접수, 민원 내용·사전통지서 링크 클릭 유도 수법을 경고함. 해당 공지에서 관련 민원 문자를 발송하지 않는다고 안내함 | 다른 지자체의 정책, 2026년 현재 모든 통지 방식 |
| 강동구 청소행정과, 2025-07-04 | 쓰레기 과태료 안내용 URL을 보내지 않는다고 안내함 | 문자 발송 자체가 전부 없다는 주장, 다른 지역·다른 과태료 업무의 정책 |
| 경찰청 정책뉴스, 2024-05-01 | 당시 폐기물 과태료 통지 방식과 관공서 사칭 문자에 대한 공식 확인 방법을 안내함 | 게시 이후 모든 지자체 정책이 변경되지 않았다는 주장 |

공지를 작성한 기관과 문자에서 발신자라고 주장하는 기관은 다를 수 있다. 전주시·강동구가 경고한
수법이라는 이유로 입력 문자에 전주시·강동구 이름이 있었다고 추출하지 않는다.

원문을 오늘 확인한 날짜(`checked_at`)와 정책의 적용 기간(`applies_to.period`)도 다르다.
과거 공지를 읽었다는 사실만으로 현재 발송 정책을 검증했다고 기록하지 않는다.
NR-0002~0004와 강동구 절차를 분리한 NR-0009는 모두 `draft`다. 원문 대조와 적용 범위 검토 없이 운영 규칙에 사용하지 않는다.

## 3. 높은 주의를 고정 적용하는 조건

### 공식 절차와의 충돌로 경고하는 경우

다음 네 조건이 모두 충족되어야 한다.

1. **발신 주장:** 문자에서 특정 기관·부서를 발신자로 내세운다. 사용자 거주지만으로 발신 기관을 추정하지 않는다.
2. **업무:** 쓰레기 무단투기·분리배출 위반 신고 또는 폐기물 과태료 안내 업무임을 원문으로 확인한다.
3. **요구 행동:** 그 안내를 확인하기 위해 문자 속 링크를 누르라고 사용자에게 직접 요구한다.
4. **공식 근거:** 그 기관·지역·업무·시점에 적용할 수 있도록 검토된 공식 자료가 해당 발송 방식을 부정한다.

제시한 기관명·업무·행동마다 입력 원문 근거를 남기고, 공식 자료에는 레코드 ID·출처·적용 범위를 남긴다.
기관명이나 단어 일치만으로 충족시키지 않는다. 부정문·예방 안내·인용·다른 사람의 사례 소개도 확인한다.
조건이 충족되면 같은 근거에는 같은 등급을 부여한다. LLM이 등급을 임의로 선택하지 않는다.
링크·페이지 분석은 계속 수행하고 확보한 결과와 충돌이 있으면 숨기지 않는다.

### 별도의 위험 행동으로 경고하는 경우

알려진 사례에 없거나 지역을 몰라도 위험 행동의 근거를 확보하면 경고한다.
예를 들어 과태료 확인을 빌미로 인증번호 전달이나 원격제어 앱 설치를 직접 요구하는 경우다.
예방 안내의 인용이 아니라 현재 사용자에게 하는 요구인지 검증해야 한다.
일반적인 앱 설치·납부 안내를 모두 위험하게 취급하는 규칙을 추가한다는 뜻은 아니다.

### 그 외

- 알려진 수법의 기관 주장·명분·요구 행동이 일치해도 적용 가능한 공식 절차가 없으면 **주의 필요**로 두고 추가 분석한다.
- 기관이나 업무만 언급되면 **확인 필요**로 두고 다른 구체적인 행동을 살핀다.
- 검색 유사도는 관련 자료를 찾는 값이다. 숫자가 높다는 이유로 높은 주의 등급을 부여하지 않는다.
- 페이지 수집 실패는 별도 한계다. 문자에서 이미 확보한 근거를 버리거나 실패를 새로운 위험 근거로 삼지 않는다.
- URL이 없더라도 문자에 대한 분석·확인 안내는 필요하다. 링크 검사 불가를 문자 안전으로 해석하지 않는다.

## 4. 비교할 합성 사례

아래 문자는 **직접 작성한 가상 예시**다. 실제 수신 문자나 검증된 정상·악성 평가 데이터가 아니다.
`notice.example`은 예시 주소이고 악성 주소로 확인된 것이 아니다. 기대 결과는 제안 기준에 대한 검토용이며,
현재 코드 실행 결과나 실제 탐지 성능을 의미하지 않는다.

## 5. 사용자 안내 예시

**공식 절차와 충돌하는 근거가 검토된 경우**

> 사칭이 의심되는 문자입니다. 문자 속 링크를 누르지 말고 공식 경로에서 확인하세요.
> 문자는 해당 기관의 쓰레기 과태료 안내라고 주장하지만, 검토한 공식 안내는 이 업무에 문자 링크를 보내지 않는다고 설명합니다.
> 실제 과태료 부과 여부는 해당 지자체 공식 홈페이지에서 대표번호를 직접 찾아 담당 부서에 확인하세요.

실제 답변에는 해당 기관명과 근거 출처·게시 시점을 표시한다. 링크·페이지에서 확인하지 않은 사실을 덧붙이지 않는다.

**알려진 수법과 닮았지만 기관·현재 절차를 모르는 경우**

> 쓰레기 신고를 내세워 링크 클릭을 유도하는 알려진 사칭 수법과 비슷합니다.
> 어느 지자체에서 보낸 것인지와 실제 과태료 부과 여부는 확인하지 못했습니다.
> 문자 속 링크·번호 대신 관련 지자체 공식 홈페이지에서 연락처를 직접 찾아 확인하세요.

관할 기관을 모르면 관할 시·군·구 또는 발신 기관이라고 주장한 곳을 추가로 확인한다.
사용자 거주지가 위반 장소·담당 기관이라고 단정하지 않으며 과태료·납부 기한을 무시하라고 안내하지 않는다.

## 6. 다음 구현 전에 반영할 것

1. **초안 수정 완료:** NR-0003을 전주시의 2024년 안내로 한정하고, 강동구의 2025년 링크 미발송 안내를 NR-0009로 분리했다. 문자 미발송과 링크 미발송을 구별한다.
2. **초안 수정 완료:** NR-0004의 `주소지` 기준을 실제 담당 지자체 확인으로 바로잡고, 문자 속 번호 대신 공식 홈페이지의 연락처를 안내하도록 예외·적용 주의를 보완했다.
3. 참고 자료를 사람이 검토하고 적용 범위를 확정한다. 과거 자료의 재열람만으로 현재 정책을 검증했다고 하지 않는다.
4. **1차 연결 적용:** 기존 `message.details.reason.text`에 원문 근거가 있는 기관·명분과 행동 인용을 보존하고, 판단 보류 카드(R9)에 표시한다. 검색 실패 시 확보한 내용과 분석 한계를 함께 남긴다. 카드 본문은 400자에 맞춰 요약하며 원래 응답 설명은 보존한다. 이 변경은 기관 정보를 새 구조화 필드로 전달하거나 참고 자료를 운영 검색에 연결하는 단계까지 포함하지 않는다.
5. 공식 절차를 새 위험 근거로 사용하는 것은 현재 `norm_rules` 양식의 설명 용도를 확장한다.
   기존 응답 계약에는 이 위험 근거 유형과 주의 등급이 없다. 판정 근거·검증 방식·실패 시 처리·BE/FE 전달 방식을 함께 정한 뒤 구현한다.

문서 사례만으로 탐지 성능을 입증할 수 없다. 구현 단계에서는 위 반례가 잘못 경고되지 않는지 실행 확인하고,
실제 출처를 확인한 별도 문자로 정상 문자를 위험하게 표시하는 비율과 새 수법을 놓치는 비율을 평가한다.
