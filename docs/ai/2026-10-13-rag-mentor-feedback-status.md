`feature/rag-fix-ai` → `feature/rag-fix` → `develop` 순서로 PR 을 올린다.

## 2. 단계별 결과

### 1단계 — 운영과 같은 입력으로 평가

- 운영에서 AI 는 BE 가 주소를 지운 본문만 받는다. 평가도 출처 원문(`text`)이 아니라 주소를 지운 `message` 로 검색한다.
- 이 조건으로 기준값을 다시 골라 운영 값(`ai/src/ai/kb/search.py` 의 `DEFAULT_MIN_SIMILARITY`)을 0.2345 로 맞췄다.
- 결과: test 스미싱 hit@3 29.0% (9/31). 잠정 목표 50% 에 못 미친다. 리포트 `ai/eval/reports/2026-10-07-rag-tfidf-message.md`.
- 가정: BE 가 스킴 없는 주소(`www.…`)까지 지운다. BE 와 확인 중이다. `SSG.COM`·`APPLE.COM` 이 든 5행은 판단을 미루고 평가에서 뺐다.

### 2단계 — KB 정리

- KB 에 거의 같은 사례가 있는 평가 문자에 `near_dup_of` 를 붙이고, 점수를 "아는 캠페인"과 "새 캠페인"으로 나눴다.
  test hit@3 아는 캠페인 85.7% (6/7), 새 캠페인 12.5% (3/24). TF-IDF 는 숫자·이름만 바뀐 변형은 찾지만 다른 표현은 거의 못 찾는다.
- KB 출처 현황과 새 레코드 규칙(공개 웹은 출처 URL, 팀 수신분은 수신일·라벨 근거, 근거가 없으면 draft)을 `ai/src/ai/kb/README.md` 에 적었다.
- 미룬 것: KB 내부 근접 중복 48쌍 정리.

### 3단계 — 업무별 공식 안내 자료

지원 업무는 택배 배송·주소 확인, 과태료, 해외결제·구매 승인 알림 셋이다. 자료 18건(`ai/src/ai/kb/norm_rules/`):

| 업무 | 자료 | 정식(curated) |
|---|---|---|
| 과태료 | NR-0002 ~ NR-0009, NR-0020 | NR-0020 (검토자 김수호, 2026-10-14) |
| 택배 | NR-0010 ~ NR-0015 | NR-0011 ~ 0015 (검토자 강성윤, 2026-10-11) |
| 해외결제 | NR-0016 ~ NR-0019 | NR-0019 (조건을 `결제·승인` 으로 바꿔 검토, 김수호, 2026-10-14) |

- 발췌문은 모두 출처 원문을 내려받아 글자 그대로 있는지 기계로 대조했다.
- 운영 연결: `ai/src/ai/kb/guidance.py` 의 `find_guidance()`. 최종 결과의 정해진 값(주제·브랜드·요구 행동·공식 도메인 일치)만 보고
  정식 자료 중 맞는 것을 최대 3개 돌려준다. 판정에는 쓰지 않고 LLM 도 쓰지 않는다. 고르는 조건은 각 자료의 `match` 에 적었다.
- 설계 `docs/superpowers/specs/2026-10-11-norm-guidance-design.md`. BE·FE 후속은 이슈 #69("자세히 보기" 확인 방법 카드).

### 4단계 — 평가셋 확장과 확인 경로 평가

- 새 문자 36건 = 종류 3개 × 업무 3개 × 4건.
  - 종류: 정상 전자고지(`official_notice`), 명분은 같고 요구 행동이 다른 문자(`same_pretext`), 기관·관할을 알기 어려운 문자(`unclear_org`)
  - 공식 출처 예시 6건(한진택배·CJ대한통운·강동구청·신한카드 공지, 원문 대조)을 먼저 넣고, 빈 칸 30건은 사용자가 검수한 합성 문자로 채웠다.
- 모든 평가 행에 정답 업무(`expected_business`)를 붙였다. 결제 문자는 사람이 한 건씩 확인했다.
- 새 스크립트 `ai/eval/guidance_eval.py`: 문자마다 `find_guidance()` 가 맞는 업무의 확인 방법을 안내했는지 맞음·빠짐·엉뚱함·맞게 없음으로 센다.
- `ai/eval/rag_eval.py` 에 새 문자 종류별 표를 더했다.
- 설계 `docs/superpowers/specs/2026-10-11-eval-expansion-design.md`, 계획 `docs/superpowers/plans/2026-10-11-eval-expansion.md`.

NR-0019·NR-0020 검토(10-14)와 국내 카드 승인 평가 라벨(10-14)은 정했다. 결과는 리포트 `ai/eval/reports/2026-10-14-guidance.md`:
과태료 40/58, 해외결제·구매 승인 26/27 맞게 안내, 정상 문자 엉뚱함 10 (2.1%, 변경 전과 같음).

## 5. 알려진 한계

- 새 문자 36건 중 30건, 정상·hard negative 평가 문자 대부분이 합성이다. 이 수치를 실제 성능으로 인용하지 않는다.
- 확인 경로 평가는 고정 규칙만 쓴다. 운영에서는 AI 가 요구 행동·택배사를 더 뽑으므로 실제 안내는 조금 더 붙을 수 있다.
  고정 규칙은 새 문자 36건의 요구 행동을 2건만 맞게 찾았다. AI 를 넣은 평가는 아직 하지 않았다.
- 실물 정상 문자가 적다(택배·쇼핑몰 5건). 팀 실물을 모으면 같은 `id` 로 바꾼다.
