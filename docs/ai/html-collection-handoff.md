# HTML 수집·검사 인계 협의안

이 문서는 격리 수집기와 BE에 전달할 협의안이다. 수집 자료의 분석 주체는
메인 서버 AI이며 BE는 수신 검증과 함수 호출을 담당한다. 기존 보안
체크리스트의 원본 HTML 금지와 info HTML 계약은 아직 정합성 합의가 필요하다.
여기에 적힌 DOM 항목 전부가 현재 AI 검사기에서 해석되는 것은 아니다.

## 목적과 책임 경계

격리 수집기는 JavaScript 실행 후 관측한 페이지에서 제한된 DOM 자료를 만든다.
BE는 응답 크기, UTF-8, 스키마와 수집 상태를 검증한 뒤 로컬 Python 패키지인
AI를 호출한다. AI는 전달받은 자료만 검사하고 최종 환경 분석을 조립한다.
페이지 접속, 브라우저 실행, 네트워크 차단, 컨테이너 종료와 임시 자료 삭제는
수집 측 책임이다.

현재 연결 인터페이스는 `IsolatedPage(brand, category, info)`와
`finalize_analysis(..., failure=...)`의 Python 인자뿐이다. `info`는 HTML 문자열이다.
합의되지 않은 JSON envelope, 원격 필드, HTTP API 또는 범용 `PageElement` 확장은
이번 구현에 포함하지 않는다. AI가 반환하는 근거 오프셋은 브라우저 원본 DOM이
아닌 전달된 `info` 문자열을 기준으로 한다.

## 범용 DOM 수집 목록

수집 대상을 특정 택배사나 업종 키워드로 제한하지 않는다. 페이지가 주장하는
서비스, 상황, 요구 행동, 요구 정보와 조건, 관련 버튼, 선언된 목적지의 관계를
보존한다.

| 묶음 | 보존할 내용 |
| --- | --- |
| 정체성 | 문서 제목, 주요 제목, 사이트명, 로고 대체 텍스트 |
| 본문 | 문단, 목록, 표, `dl`, `main/article/section`과 일반 컨테이너의 의미 있는 텍스트 |
| 조건·절차 | 금액, 기한, 수수료, 자격, 환불·이용 조건을 포함한 전체 문맥 |
| 입력 | `input/textarea/select`, 선택지 문구, `type/name/autocomplete/required/readonly/disabled` |
| 입력 설명 | `label/legend/placeholder/aria-label`과 `aria-labelledby/aria-describedby` 참조 텍스트 |
| 폼 관계 | `form/fieldset`, `id/for/form`, 폼 밖 입력·제출 버튼의 실제 연결 |
| 행동 | 링크, 버튼, 제출 입력, `role=button`, 주변 설명과 표시용 `value` |
| 목적지 | `href/action/formaction/method/formmethod/download`, 원래 참조와 기준 URL |
| 연락 | `tel`, `mailto`, 메신저 링크와 연락을 요구하는 문맥 |
| 페이지 상태 | 경고, 오류, 로그인 벽, 접근 차단, CAPTCHA, 완료 안내 |
| 외부·시각 콘텐츠 | `iframe/img/object/embed`의 출처, 제목, 대체 설명, 주변 문맥과 내부 수집 여부 |

JavaScript·CSS 원문, 쿠키, 인증 토큰과 입력된 개인정보는 기본 전달 대상에서
제외한다. 정제, 마스킹 또는 잘림이 있으면 그 상태를 표시하고 원본 전체 DOM과
같은 자료로 부르지 않는다. 화면 가시성, DOM 존재, 선언된 제출 주소와 실제
통신·다운로드는 서로 다른 관측값이다.

## 정상·의심 사례 비교 기준

| 사례 | 함께 수집할 비교 문맥 |
| --- | --- |
| 배송 | 배송 상태, 주소 수정 이유, 입력·결제·설치 요구 |
| 금융·계정·구독 | 거래·정지·갱신 설명, 인증·결제 항목, 목적지 |
| 공공기관·세금·지원금 | 기관 주장, 신청·납부 근거, 금액·기한·요구 정보 |
| 청첩장·부고·행사 | 행사 내용, 열람 목적, 추가 설치·로그인 요구 |
| 채용·부업 | 업무·보상 조건, 선납·수익 인출 요구, 연락 경로 |
| 쇼핑·중고거래 | 상품·주문·환불 설명, 결제·외부 연락 유도 |
| 예약·병원·학교 | 예약·공지 목적, 필요한 입력, 첨부·연락 경로 |
| 정상 정보 제공 | 본문과 안내를 보존하고 행동 요소가 없다는 이유로 수집 실패로 표시하지 않음 |

로그인, 결제, 외부 도메인 또는 기관 로고만으로 악성을 판정하지 않는다. 경고,
부정문과 인용문을 잘라 실제 행동 요구로 바꾸지 않는다. 수집하지 않은 영역은
`없음`이 아니라 `미확인`으로 전달한다.

## 별도 메타데이터 요구사항

최초·최종 URL, 이동 경로, 수집 시각, JS 실행 후 DOM이라는 수집 방식,
잘림·차단·실패 이유, iframe·Shadow DOM·이미지 텍스트 수집 범위가 필요하다.
형식과 값은 BE·수집 담당자와 합의해야 하며 현재 `info`에 임의 JSON으로 넣지
않는다. OCR, 자동 입력, 클릭, 폼 제출과 파일 실행은 초기 범위에서 제외한다.

## 수집 단계 제한

| 항목 | 상태 |
| --- | --- |
| 브라우저 작업 | 기존 12초 예산부터 실측하고 외부 관리자가 초과 작업을 종료 |
| 이동 | 최대 5홉 제안, 모든 후속 요청에 목적지 정책 적용 |
| 동시 실행 | 1건부터 측정, 대기열도 유한하게 제한 |
| 메모리·CPU·디스크 | 컨테이너·브라우저·임시 파일을 포함해 별도 운영 상한 합의 필요 |
| BE 응답 수신 | 전체 응답 byte 상한과 스트리밍 중단 정책을 별도로 합의 |
| 인코딩·스키마 | UTF-8과 수집 상태를 수신 경계에서 검증하고 실패 이유 전달 |

응답 전체 byte 상한은 아래 HTML 128 KiB 상한과 별개다. AI 제한은 이미 수신한
응답의 메모리 사용이나 브라우저의 거대한 DOM 생성을 막지 않는다. 인코딩할 수
없는 자료는 정상·악성 판정이 아닌 수신 검증 오류로 다룬다.

## AI 검사 단계 제한

| 항목 | 현재 초기값 | 결과 |
| --- | --- | --- |
| HTML UTF-8 크기 | 131,072 bytes (128 KiB) | `INPUT_TOO_LARGE`, 파싱 생략 |
| 요소 수 | 2,000 | `PARTIAL_CONTENT` |
| 본문 텍스트 | 16,000자 | `PARTIAL_CONTENT` |
| 노드 깊이 | 64단계, 루트 깊이 1 | `PARTIAL_CONTENT` |
| 협력적 검사 시간 | 0.100초 | `TIMEOUT` |
| 검사 결과 JSON | 262,144 bytes (256 KiB) | 뒤 후보를 제외하고 `PARTIAL_CONTENT` |
| LLM user JSON | 131,072 bytes (128 KiB) | `INPUT_TOO_LARGE`, LLM 호출 생략 |
| 인코딩 불가 Python 문자열 | UTF-8 계약 오류 | `ValueError` |

JSON 크기는 `ensure_ascii=False`, `separators=(",", ":")` 기준이다. 100ms는
파싱·분류·근거 생성을 함께 확인하는 협력적 예산이며 단일 파서·정규식 연산을
강제 종료하는 보장이 아니다. 위 숫자는 운영 실측 결과가 아닌 초기 가설이다.
부분 수집과 제한 초과는 안전 또는 악성 근거로 바꾸지 않으며, 이미 확정된
source-local 근거와 정상 메시지 결과를 보존한다.

## 불신 입력과 출력 방어

저장한 DOM, URL, 페이지 지시문과 수집 메타데이터는 저장 후에도 불신 입력이다.
관리자 화면에 넣을 때는 HTML 텍스트·속성·URL 문맥에 맞게 출력 시점에
이스케이프하고, 로그에서는 구조화 필드와 제어문자 처리 규칙을 적용한다. 다른
문맥에 재사용하면 해당 문맥에 맞게 다시 인코딩한다. 입력 검증이나 저장 시
정제는 관리자 화면·로그·응답의 출력 이스케이프를 대신하지 않는다. 저장된
내용을 HTML이나 명령으로 실행하지 않는다.

## 실제 AWS 환경 검증 목록

다음 항목은 배포 완료 증거가 아니라 도입 전에 확인할 측정 목록이다.

- 동시 실행 1건에서 cold start, peak RSS와 p95 전체 시간을 측정한다.
- 대기열·메모리·시간 초과 시 새 작업을 유한하게 거부하는지 확인한다.
- 메타데이터 서비스, 내부 주소, BE와 관리 인터페이스 접근을 차단한다.
- 컨테이너를 강제 종료한 뒤 프로세스·임시 파일·다운로드 자료가 남지 않는지 확인한다.
- 강제 종료 직후 다음 작업이 성공하는지 확인한다.
- 자료 삭제와 로그 회전이 디스크 상한 안에서 동작하는지 확인한다.

실측 전에는 2 vCPU·4GB 환경의 안전성, 일반 스미싱 판별 정확도, 100ms 강제
종료 또는 운영 처리량이 입증됐다고 기록하지 않는다.
