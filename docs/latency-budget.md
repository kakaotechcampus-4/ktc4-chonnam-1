# 지연 예산

카카오 스킬 SLA 5초. **전체 데드라인 4.0초** (1초 안전 마진).

| 단계 | 상한 | 초과 시 |
|---|---|---|
| URL 추출 (정규식) | 50ms | LLM 추출로 승격 |
| 리다이렉트 추적 | 2.0s | 추적 중단, "확인 불가"로 판정 |
| 화이트리스트 대조 | 50ms | — |
| LLM 설명 생성 | 1.5s | 템플릿 문장으로 폴백 |
| 응답 조립 | 100ms | — |

## 규칙

- 리다이렉트는 최대 3홉, 홉당 1초, HEAD 요청.
- 각 단계는 예산 초과 시 **거기까지의 결과로 응답을 만든다.** 전체 실패로 만들지 않는다.
- 조회한 URL은 캐싱한다. 스미싱은 대량 발송이라 적중률이 높다.

구현 위치: `backend/src/server/orchestration/`

## 측정

1주차에 실제 스미싱 URL 20건으로 리다이렉트 추적 시간을 재고 이 표를 갱신한다.
결과는 `docs/experiments/` 에 기록.
