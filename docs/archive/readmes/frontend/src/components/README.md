# components

표시 전용 컴포넌트. 가드를 통과한 뷰모델만 받습니다.

| 컴포넌트 | 역할 |
| --- | --- |
| `EvidenceCard` | 네 칸 — 문자 주장 / 관측 / 해석 / 미확인 |
| `HeldCard` | 판단 보류 — 확인된 것 / 부족한 것 / 결론 |
| `ObservationList` | 관측 원자료. 관측 시각·출처를 항상 함께 |
| `MaskedUrl` | 의심 URL. 클릭 불가 텍스트로만 |
| `OfficialRoutes` | 공식 확인 경로. 목록이 없으면 회사 미특정 안내 |

## 규칙

- **미확인 칸은 항상 있습니다.** 비어 있으면 카드를 그리지 않고 오류로 처리합니다. 세 칸만 보이면 사용자에게는 "확인 못 한 게 없다"로 읽히고, 그건 안전을 보증한 것과 같습니다.
- **해석은 관측이 있을 때만 그립니다.** `observations`가 비면 `interpretation`을 받더라도 그리지 않습니다.
- `dangerouslySetInnerHTML` 금지. 관측 문자열은 전부 텍스트 노드로만 출력합니다. 대상 페이지 본문은 공격자가 쓴 것이라는 전제로 다룹니다.
- **판단 보류를 오류 톤으로 그리지 않습니다.** 회색 경고로 보이면 사용자가 "그럼 직접 눌러보자"로 가고, 그 순간 제품이 하려던 일이 무너집니다.
