# lib

BE 응답을 화면이 쓸 형태로 바꾸고, 나가면 안 되는 것을 막습니다. **이 폴더가 프론트의 안전장치입니다.**

| 모듈 | 역할 |
| --- | --- |
| `adapters/` | BE 응답 → 뷰모델. 관측 필드가 바뀌어도 컴포넌트가 안 흔들리게 하는 완충층 |
| `guards/` | 출력 가드 (아래) |
| `polling/` | 상태 조회. 탭 이탈·복귀 시 복원 |
| `api/` | 서버 측 BE 호출 클라이언트 |

## 출력 가드

| 가드 | 막는 것 |
| --- | --- |
| `assertUnverified()` | 미확인 칸이 빈 채로 결과가 나가는 것 |
| `assertNoAssurance()` | "안전합니다" 류 보증 표현이 나가는 것 |
| `maskUrls()` | 의심 URL이 눌리는 상태로 나가는 것 |

- 가드는 **조용히 넘어가지 않고 예외를 던집니다.** 반쪽짜리 결과를 내보내는 것보다 아무것도 안 내보내는 쪽이 낫고, 실패가 눈에 보여야 원인이 BE 데이터인지 추적할 수 있습니다.
- 가드를 우회하는 경로를 만들지 마세요. 컴포넌트에서 원본 응답을 직접 읽는 코드가 생기면 그때부터 가드는 없는 것과 같습니다.
- 가드 발동 건수는 지표로 수집합니다. 정상값은 0입니다.
