## CI 게이트

- 보증 표현 검출 → **빌드 실패**
- 출력 문자열에서 원문 URL 패턴 검출 → **빌드 실패**
- 결과 화면 스냅샷 3종 변경 시 리뷰 필수

## 반드시 유지할 것

- **인젝션 픽스처는 상시 테스트에 포함합니다.** 관측 본문의 지시문이 화면 구조나 동작을 바꾸지 못하는지가 이 제품에서 가장 위험한 실패입니다.
- 접근 실패에서 판단 보류가 나오는 것은 **정답 동작**입니다. 실패 케이스로 적지 마세요.
