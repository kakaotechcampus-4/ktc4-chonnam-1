# 모델 호출 규칙

프로토타입의 LLM 역할은 브랜드·주장 목적·요구 행동 추출과 관측·결과 설명이다. 최종 판정은 결정적 코드가 수행한다. RAG 검색 유사도를 악성 확률이나 판정 기준으로 사용하지 않는다.

입력에서 URL과 개인정보를 처리하고 문자·관측·검색 자료를 지시와 구분한다. 구조화 출력과 원문·관측 근거를 검증한다. 상세 스키마는 후속 확정이며 문서에 새 JSON 예시를 두지 않는다.

텍스트가 없으면 추출을 생략한다. 관측 자료가 없으면 사이트 내용에 대한 해석을 만들지 않는다. 모델 실패·시간 초과 시 미확인 범위를 남기고 확인된 근거를 보존한다. 설명은 템플릿으로 폴백한다.

자율 보강 도구 선택과 멀티모달 격리 분석은 현재 필수 호출이 아니다. 자체 Docker sandbox는 향후 논의 대상이다.

모델·프롬프트 버전, 지연, 호출·재시도 횟수, 토큰·비용을 기록하고 임베딩 비용은 별도 집계한다. 개인정보·인증정보는 로그에서 제외한다. 모델·시간·재시도 설정은 평가 후 확정한다.
