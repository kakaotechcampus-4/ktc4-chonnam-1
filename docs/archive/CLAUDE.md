# docs/archive

**이 폴더의 문서는 작업할 때 참고하지 않는다.**

이미 구현이 끝났거나 다른 문서로 대체된 계획서·설계 초안·인계 문서·폴더 README를
기록용으로만 보관한다. 내용이 현재 코드와 다를 수 있다. 사실 확인은 코드를 기준으로 하고,
현재 기준 문서는 `docs/README.md` 인덱스를 따른다.

- 이 폴더의 파일을 읽거나 검색 결과로 인용하지 않는다. 사용자가 명시적으로 요청할 때만 연다.
- 새 문서를 이 폴더에 추가하지 않는다. 기존 문서를 정리해 옮길 때만 추가한다.
- `readmes/` 는 원래 경로를 유지해 옮긴 폴더 README다 (예: `readmes/backend/src/server/api/README.md`).
