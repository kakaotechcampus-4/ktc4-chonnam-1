# ADR 0010 — 자주 사칭되는 공공기관은 주의까지만 쓴다

상태: 채택 (2026-11-07 구현 확인). 제안 2026-11-04

## 맥락

V-5 목록은 수사·감독 기관만 담는다(v3 §5.5). 정상 은행 미납 안내가 의심으로 나오는 것을 막으려고 좁힌 것이다.
그래서 `[국세청] 고객님 앞으로 미납된 종합소득세가 있습니다` 처럼 다른 공공기관을 내세우고 요구가 없는 문자는
근거가 하나도 남지 않아 `input_required` 가 되고, "확인할 주소가 없어요" 카드가 나갔다. 대표번호 KB 에 국세청(126)이
있어도 `listed_institution` 이 거짓이라 안내하지 못했다.

## 결정

1. 자주 사칭되는 공공기관을 `PUBLIC_INSTITUTION_PATTERN`(`ai/src/ai/case/lexicon.py`)으로 따로 둔다:
   국세청, 세무서, 관세청, 건강보험공단, 국민연금, 노동부, 우체국, 출입국.
2. 여기에 걸린 주장은 `institution_claim` 이 되어 주의와 대표번호 안내를 내지만, `counts_for_floor` 는 늘 거짓이다.
   자기소개 꼴과 부탁 꼴이 맞아도 L-3(`suspected`)을 세우지 않는다.
3. 사례 첨부 관문은 지금 목록(`INSTITUTION_PATTERN`)을 그대로 쓴다. 학습 가중치와 `feature_hash` 가 이 목록에 기댄다.
4. 은행·카드사·통신사·택배사는 이번에도 넣지 않는다.

기관은 사례 KB 에 나온 횟수와 사칭 사례 보도를 보고 골랐다. 기관별 공식 사칭 통계는 찾지 못했다.

## 결과

대리 평가(어휘표 읽기 → verify → gate, LLM 없음, 2026-11-04). 운영은 LLM 읽기가 먼저라 운영 수치가 아니다.
저장소의 `ai/eval/datasets` 를 썼고 합성 데이터가 많다.

| 데이터 | 건수 | 주의(이전 → 이후) | L-3 근거(이전 → 이후) |
| --- | --- | --- | --- |
| 문자 정상(`benign`) | 21 | 9 → 11 | 0 → 0 |
| 문자 정상(`rag_testset`) | 578 | 186 → 232 | 0 → 0 |
| 문자 스미싱(`rag_testset`) | 103 | 20 → 28 | 0 → 0 |
| 문자 스미싱(`smishing`) | 127 | 2 → 6 | 0 → 0 |
| 통화 정상 | 338 | 256 → 264 | 18 → 18 |
| 통화 사기 | 119 | 117 → 117 | 6 → 6 |

- 진짜 공공기관 안내에도 주의가 나간다. 위 정상 문자에서 늘어난 48건은 주로 우체국·국세청·건강보험·국민연금이다.
  링크가 있는 문자는 실제로는 이 판정을 타지 않으므로 그만큼은 과대 집계다.
- 같은 목록을 L-3 에도 쓰면 통화 사기 근거가 6 → 14 로 늘지만 통화 정상도 18 → 35 로 늘어 채택하지 않았다
  (이 측정에는 근로복지공단이 들어 있었고 결정 목록에는 없다).
- 관세청·노동부는 대표번호 KB 에 없어 번호 안내가 나가지 않는다.
- 우체국은 정상 안내가 가장 많이 걸린다. 오탐이 문제가 되면 먼저 뺄 후보다.
