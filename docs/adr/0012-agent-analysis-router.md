# ADR 0012 — 돌릴 분석은 에이전트가 고르고, 필수 분석과 판정은 코드가 한다

상태: 구현 (2026-11-11), 기본값은 꺼짐. 실제 LLM 으로는 아직 돌려 보지 않았다

## 맥락

`run_analysis` 는 `read_message` 뒤에 `if 링크` 한 줄로 갈렸다. 링크가 있으면 수집·공식 대조·문자 신호, 없으면 사칭 주장 분석이다.
어떤 분석을 돌릴지가 코드 분기에 박혀 있어서 새 사기 시나리오를 붙일 때마다 분기를 고쳐야 했다.

LLM 이 도구 호출로 돌릴 분석을 고르는 구조로 바꾼다. 목적은 구조와 확장성이고 정확도 향상이 아니다.
지켜야 할 것은 그대로다. 판정은 결정적 로직이 하고(절대 원칙 1·2), 카드는 지금과 글자 하나까지 같아야 하며,
전체 분석은 45초 안에 끝나야 한다. 에이전트가 읽는 본문과 수집한 페이지는 공격자가 쓴 글이다.

## 결정

1. **요청마다 분석 장부(board)를 둔다.** `(도구, 링크 번호)` 마다 Task 하나다(`ai/src/ai/agent/board.py`).
   누가 불러도 같은 Task 의 결과·예외를 받는다. 먼저 부른 쪽이 시작하고 나중에 부른 쪽은 이어 받는다.
2. **카드는 지금의 고정 흐름이 만든다.** 그 코드(`main._link_cards`·`run_message_case`)가 근거를 직접 만들지 않고
   `board.get` 으로 꺼낸다. 카드가 읽는 분석(수집, 공식 대조, 문자 신호, 판단 보류일 때의 문자 게이트)은 카드가 꺼내므로
   에이전트가 부르지 않아도 돈다. 필수 분석 목록을 따로 적지 않는다. 카드가 읽는 것이 곧 필수다.
3. **에이전트는 같은 장부에 분석을 먼저 올린다.** `ai/src/ai/agent/loop.py` 의 루프가 LLM 에 도구 목록을 주고,
   LLM 이 부른 도구를 `board.get(..., by="agent")` 로 시작한다. 에이전트의 첫 턴이 끝나 호출이 장부에 오르거나
   루프가 끝나면 카드 코드가 출발한다. 그 뒤로는 둘이 함께 돈다.
4. **폴백 경로가 따로 없다.** 에이전트가 꺼져 있거나 실패하면 카드 코드가 빈 장부에서 꺼낼 뿐이고, 그것이 지금의 고정 흐름이다.
5. **링크 추출은 도구가 아니다.** `read_message` 는 코드가 먼저 돌린다. 도구 스키마가 그 결과(링크 수)에서 나온다.
6. **끄고 켜기는 `AGENT_MODEL` 이다.** 없으면 루프를 돌리지 않는다.

도구는 `main._analysis_tools` 에 모여 있다. 새 시나리오는 여기에 `Tool` 하나를 더한다.
카드가 그 결과를 읽어야 하면 카드 코드에서 `board.get` 으로 꺼낸다.

| 도구 | 감싼 함수 | 카드가 읽나 |
| --- | --- | --- |
| `collect_link` | `scanner.isolation_client.collect_url_isolated` | 링크마다 읽는다 |
| `check_official_domain` | `main.build_ai_url_analysis` | 링크마다 읽는다 |
| `analyze_message_signals` | `ai.pipeline.analyze_message_part` | 링크가 있으면 읽는다 |
| `analyze_claims` | `ai.case.analyze_message_case` | 링크가 없거나 링크 결과가 판단 보류면 읽는다 |
| `search_similar_cases` | `ai.kb.search.search_cases` | 읽지 않는다 |
| `check_official_numbers` | `ai.kb.numbers` | 읽지 않는다 |

## 안전장치

| 지킬 것 | 어디서 지키나 |
| --- | --- |
| 필수 분석은 건너뛸 수 없다 | 카드 코드가 `board.get(need.official, n)` 없이는 `finalize_analysis` 를 부를 수 없다. 공식 대조가 그 링크의 수집과 문자 신호를 끌어온다 |
| 도구 입력 제한 | 도구 인자는 링크 번호 하나거나 없다. 주소는 `reading.links[n - 1]` 에서만 나온다(원문 대조를 거친 링크, ADR 0007). 스키마의 `enum` 과 별개로 `_parse_call` 이 모르는 도구·여분 인자·범위 밖 번호를 실행 전에 버린다 |
| 원본 HTML 을 보지 않는다 | 도구 결과는 `_show` 로만 LLM 에 간다. 관측 값은 `bool`·`int`·`Enum`·`None` 뿐이고 글자가 하나라도 있으면 관측을 통째로 버린다 |
| 상한 | LLM 4턴, 도구 5회, 턴당 5초. 카드가 끝난 뒤에는 3초까지만 에이전트를 기다리고, 분석 시작 40초 뒤로는 기다리지 않는다 |
| 실패해도 답이 나간다 | LLM 오류·시간 초과·설정 누락·가리기 실패는 에이전트만 끝낸다(`llm_error`). 시작해 둔 분석은 장부에 남아 카드가 이어 받는다 |
| 판정은 그대로다 | `finalize_analysis`·`link_caution_applies`·`decide_message`·카드 렌더러는 도구가 아니고 고치지 않았다. LLM 이 쓴 글은 읽지도 저장하지도 않는다 |

본문은 `mask_pii` 로 가리고 줄마다 `<data>` 로 감싸 보낸다(`ai/src/ai/llm/claims.py` 와 같은 방식). 본문에 적힌 지시를 LLM 이
따르더라도 할 수 있는 일은 도구 5회를 낭비하거나 일찍 끝내는 것뿐이다.

`tests/test_agent_router.py` 가 문자 8종 × 방해하는 에이전트 7종으로 응답과 `final_payload` 가 에이전트를 끈 실행과 같고
링크마다 수집이 한 번인지 확인한다.

## 버린 대안

- **에이전트가 끝난 뒤 빠진 분석을 코드가 채우고, 실패하면 기존 함수를 통째로 다시 돌린다.** 카드를 만드는 경로가 둘이 되고,
  폴백이 "이미 시작한 수집"을 알아내야 한다. 장부 하나로 두면 다시 돌리지 않는 것이 규칙이 아니라 구조가 된다.
- **코드가 필수 분석을 먼저 시작하고 에이전트는 옆에서 돈다.** 지연은 0 이지만 에이전트가 고른 것이 늘 코드보다 늦어 선택이 장식이 된다.
- **수집 도구가 주소 문자열을 받고 원문과 대조한다.** 검사는 빠뜨릴 수 있다. 번호만 받으면 문자에 없는 주소를 표현할 수 없다.
- **에이전트에게 본문을 보여 주지 않는다.** 주입 통로는 없어지지만 고를 근거도 없어진다.
- **LangGraph 같은 프레임워크.** 4턴짜리 루프에 의존성을 더할 이유가 없다.

## 결과와 한계

- 카드가 같아야 하므로 에이전트가 실제로 바꾸는 것은 세 가지다. 분석이 시작되는 순서, 카드가 읽지 않는 분석(사례 검색·대표번호
  대조)을 돌릴지, 문자 게이트를 판단 보류가 나오기 전에 미리 시작할지. 카드가 읽지 않는 분석의 결과는 조사 기록에만 남는다.
- 에이전트를 켜면 수집이 에이전트의 첫 턴만큼 늦게 시작하고(상한 5초), 카드가 끝난 뒤 최대 3초를 더 기다린다(분석 시작 40초 뒤로는 기다리지 않는다).
  단계 상한을 모두 쓰는 최악에는 여유가 없어진다. 계산은 [지연 예산](../latency-budget.md)에 있다.
- 문자 게이트를 일찍 부르면 예산(`40 - 경과 초`)이 그만큼 크다. 고정 흐름이 시간 초과로 어휘표에 떨어질 만큼 늦은 요청에서만 결과가 달라질 수 있다.
- 에이전트가 다음 링크의 수집을 먼저 부르면 앞 링크의 카드가 끝나기 전에 수집이 시작된다. 수집은 여전히 한 번에 하나다(요청별 락).
  격리 수집기의 동시 처리량을 재지 않아서다.
- 링크가 여러 개이고 문자 분석이 실패하면 `[AI MESSAGE ERROR]` 는 링크마다가 아니라 요청에 한 번 남는다.
- 조사 기록은 Job 의 `investigation` 과 `[AGENT]` 로그에 도구 이름·링크 번호·부른 쪽·상태·ms 로 남는다. 카드에는 보이지 않는다.
- 게이트웨이에서 `tools=` 호출을 써 본 코드가 이 저장소에 없다. 지원하지 않으면 루프가 `llm_error` 로 끝나고 고정 흐름만 돈다.
  켜기 전에 `ai/eval/agent_router_eval.py` 로 확인한다.
- 절대 원칙 2 의 LLM 역할에 "어떤 분석을 돌릴지 도구 호출로 고른다. 필수 분석은 코드가 강제한다"가 더해진다.
  `CLAUDE.md` 문구는 이 ADR 을 채택할 때 고친다.
