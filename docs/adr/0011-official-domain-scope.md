# ADR 0011 — 공식 주소 목록은 소유 근거가 있는 기관만, 조금씩 넓힌다

상태: 채택 (2026-11-11). #161

## 맥락

공식 주소 목록(`services/official_domains.py`)은 제품 범위(택배 사칭)에 맞춰 택배사만 담았다.
실기기 테스트(2026-11-09)에서 쿠팡 배송 완료 문자(`coupa.ng` 링크)와 전남대 안내 문자(`international.jnu.ac.kr`)가
"🤔 판단하기 어려워요"로 나갔다. 설계대로의 동작이지만, 사용자에게는 "멀쩡한 문자를 판단하지 못한다"로 보인다.

목록에 없는 기관은 공식이라고 말하지 않는다. 확인하지 않은 사실을 말하지 않는 원칙이고, 잘못 넣은 도메인은
사칭 문자를 공식으로 안내하는 사고가 된다. 그래서 "넓힐지"보다 "어떤 근거가 있을 때 넣을지"를 정한다.

## 결정

1. **소유 근거가 있는 도메인만 넣는다.** 근거는 목록 주석에 남긴다. 근거를 찾지 못한 도메인은 넣지 않는다.
   - 쿠팡 `coupang.com`: 쿠팡의 서비스 도메인(회사 공시·위키 등에서 일관되게 확인).
   - 전남대학교 `jnu.ac.kr`: `.ac.kr` 은 고등교육기관만 등록할 수 있는 도메인이라 소유가 분명하다.
2. **소유 근거가 없는 단축 주소는 공식 목록에 넣지 않고 단축 주소로 본다.** `coupa.ng` 는 쿠팡 소유라는 공식 근거를
   찾지 못했다(커뮤니티 답변·트래픽 분석뿐). 단축 주소 목록(`services/link_resolution.py`)에 넣어 격리 수집기가 따라간
   도착 주소로 대조한다. 도착 주소가 `coupang.com` 이면 공식, 다른 곳이면 공식이 아니다. `bit.ly` 와 같은 방식이다.
   격리 서버 `egress-hosts` 에도 같은 호스트를 넣어야 따라갈 수 있다.
3. **AI 기관 목록(`Brand`)에 없는 기관(대학 등)은 주소로 찾는다** (#164 `brand_for_domain`). 주소로 찾은 기관은
   `official` 판정에만 쓰고 사칭(`brand_mismatch`) 근거로 쓰지 않는다. 누구나 글을 올리는 주소(`NAVER`)는 주소로 찾지 않는다.
4. 이번에는 쿠팡과 전남대만 넣는다. 다른 쇼핑몰·대학·공공기관은 실기기 사례가 나오면 같은 기준으로 하나씩 넣는다.
   한 번에 넓히지 않는 이유는 기관마다 소유 근거를 따로 확인해야 하기 때문이다.

## 결과

- #161 1번(쿠팡 `coupa.ng` → `coupang.com`)과 2번(`international.jnu.ac.kr`)은 공식 대조가 된다.
  격리 수집이 끝나야 공식 카드가 나간다(ADR 0009).
- 목록에 없는 기관은 지금처럼 판단 보류다.
- 운영: 격리 서버의 `/opt/ktc-isolation/egress-hosts` 에 `coupa.ng` 의 실제 IP 를 넣어야 한다
  (`infra/isolation/check-egress-ips.py`). 넣기 전에는 쿠팡 단축 주소가 판단 보류로 남는다.
