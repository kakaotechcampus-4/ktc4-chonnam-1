# ADR 0001: ai/ 를 별도 서버가 아닌 로컬 패키지로 둔다

## 배경

카카오 스킬 타임아웃이 5초. AI를 별도 서버로 빼면 내부 왕복(50~200ms)과
콜드 스타트(3~10초) 위험이 추가된다.

## 결정

`ai/` 는 별도 폴더·별도 pyproject를 유지하되, `backend` 에 editable 설치해
**같은 프로세스에서 함수 호출**한다. 네트워크 홉 0.

의존 방향은 `backend` → `ai` 단방향. `ai` 가 `server` 를 import하면
판정 로직이 LLM으로 새어나가므로 패키지 분리로 구조적으로 막는다.

## 대안

- `backend/src/server/ai/` 하위 모듈: 속도는 동일하나 역방향 import를 못 막음
- 별도 HTTP 서버: 5초 예산에 불리, 배포 대상 2개

## 되돌리기

폴더 이동 + import 치환으로 30분.
